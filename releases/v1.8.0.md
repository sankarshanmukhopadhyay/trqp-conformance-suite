# TRQP Conformance Suite v1.8.0 — Deterministic Evidence Replay

v1.8.0 promotes replay determinism from a verdict-only check to a first-class, machine-verifiable conformance invariant.

## Added

- Versioned replay comparison policy at `policies/replay-determinism.v1.json`.
- Canonical JSON comparison and JSON Pointer-level difference classification.
- `replay-determinism-report.schema.json` for independently validating replay evidence.
- Machine-readable determinism reports that record policy identity, version, hash, semantic hashes, and every permitted or prohibited difference.
- Negative tests proving that semantic drift fails while declared execution volatility is tolerated.
- Evidence-bundle attachment for determinism report and policy artifacts.

## Changed

- CI now performs the normative determinism gate against the fixture-pinned Baseline run.
- Live Baseline execution remains an interoperability and executable-SUT check rather than being treated as deterministic evidence.
- Replay verification remains backward-compatible with legacy verdict-only replay reports while preferring the v1.0 determinism report contract.

## Assurance impact

A successful replay now means that conformance-semantic evidence is equivalent under a declared and versioned comparison policy. Volatile execution metadata is explicitly separated from semantic evidence, making the replay decision independently auditable and suitable for downstream Assurance Hub consumption.

Closes #24.
