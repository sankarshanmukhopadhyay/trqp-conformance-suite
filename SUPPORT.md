# Support

Use GitHub Issues for reproducible conformance-suite defects, documentation problems, evidence/replay questions, and bounded feature proposals. Include the affected version/revision, expected and observed behaviour, and the smallest useful fixture or evidence reference.

Security vulnerabilities must follow [`SECURITY.md`](SECURITY.md) and must not be disclosed publicly before remediation.

CTS owns conformance execution, deterministic replay, and reassessment-plan semantics. It does not acquire authority over upstream posture/materiality decisions or downstream combined-assurance/release decisions.
